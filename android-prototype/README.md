# TAXIAPP GPS距離測定・Android試験専用アプリ

> **これは業務用TAXIAPPとは別アプリです。**
> 開発ブランチ `prototype/android-background-gps-20261016` でのみ試作。
> 業務用の `main` / GitHub Pages / 日報データ / Google連携は変更しません。

## できること

- Android標準のGPSを利用した無料の距離計測（有料Google Maps API不要）
- Android位置情報フォアグラウンドサービス（通知を表示）を利用し、画面消灯中・他のナビアプリ利用中も位置更新を受けられるようにする
- GPS距離の「累計」「実車累計」「空車累計」「計測中の実車」「直前の実車」を **0.001km（1m）単位**で画面に表示（精度が1mという意味ではありません）
- 「GPS開始」「お客様乗車」「お客様降車」「GPS停止」の4操作
- 車両トリップの実車距離を手入力してGPS距離との差（km・%）を確認
- GPS欠測回数や位置情報の最終受信時刻と状態を表示
- 測定結果をテキストとしてコピー。**GPS位置座標は永続保存・送信しない**
- 直前まで移動中→停止した最終区間を、距離と時間が妥当なら積算。停止したままのGPS位置飛びは排除
- 実車・空車の測定開始時に直前の不明な区間を強引に推測しない

## インストール用 APK の入手

GitHubの **[Android GPS試験版のビルド履歴](https://github.com/elpapityo/TAXIAPP/actions/workflows/android-gps-prototype.yml)** を開きます。

1. 成功マークの最新ビルドを開く
2. ページ最下部付近にある **Artifacts → TAXIAPP-GPS-distance-test-APK** をタップ
3. ZIPをダウンロードして展開、`app-debug.apk` を端末へインストール
4. インストールの際、Androidが求める権限を確認の上、許可する
5. アプリを開いている状態で、**正確な位置情報**を許可し、GPS測定を開始する

**注意**：これは署名がビルドごとに変わり得る検証用Debug APKです。新しいAPKに上書きできない場合があり、アンインストールすると試験用データは消えます。業務用データは影響を受けません。

## 走行テスト

1. 停車した状態で車両トリップを0.0kmにしてGPS測定開始
2. 空車走行で端末をロックしたり、Googleマップを表示するテストを実施（運転中にスマホは操作しない）
3. お客様乗車時に停車して **乗車** を押す
4. お客様降車時に停車して **降車** を押す
5. 車両トリップの「降車時値－乗車時値」を試験アプリに入力し、差を表示
6. 「計測結果をコピー」で結果を貼り付けて共有できる

## 技術情報

- コア計算とAndroidネイティブフォアグラウンドサービスを独立した2モジュールで開発
- 最低 Android 8 / target 35 / JDK 17 / Gradle 8.10.2
- GPS緯度経度は測定処理中のメモリだけで使い、永続保存しない
- Debug APKはGitHub Actionsに14日間保存する
- 実機・Googleマップ併用・画面消灯・地下道・電池最適化などの走行試験はこれから

## 未解決の制約

- **Android版でもGPS不良やOSによる計測停止は発生し得ます。** 欠測を加算でごまかしません。
- 走行距離は道路経路ではなくGPS点間の距離の合計です。カーブの間引きで過少になり得ます。
- GPSの画面上の1m表示は数値の分解能であり、実測精度は車両トリップとの差で評価します。
- このテスト版は日報システムへの自動連携・印刷・運賃計算を実装しません。
- **業務の正式記録は現行TAXIAPPと車両トリップを正としてください。**

## v0.3.0：ブラウザへのGPS距離受け渡し（テスト）

- Androidアプリ単体の距離計測は維持し、追加で`taxiappgps://measure`の呼び出しに対応。
- ブラウザの [GPS距離連携テスト](https://elpapityo.github.io/TAXIAPP/gps-import-test.html) から4種類の取得ボタンを押す。アプリ起動後の確認画面で「距離を送る」を押すと元のブラウザテスト画面へ戻り、対応する欄に反映される。
- 距離・最終GPS受信からの経過時間・欠測・測位状態のみ返す。**GPS座標、顧客情報、日報レコード、Googleシートは一切送信しない。**
- リクエスト識別番号と時刻で、重複・古い応答をブラウザが拒否する。結果は一時的なテスト表示のみ。
- この連携はAndroid GPS APK **v0.3.0以降**が必要。以前のv0.2.0では、GPSアプリ内「計測結果をコピー」からブラウザの「コピーから取得」でテスト可能。
- この画面は業務用TAXIAPPと別の専用ページで、RAW距離欄へは自動書き込みしない。車両の実トリップを正として差を確認する。
- 実際のブラウザ ↔ GPS APK往復、分割画面での復帰はGalaxy Z Fold6での実機検証待ち。

## v0.3.1：旧GPS試験版と共存する別アプリとして配布

Galaxy Z Fold6 で v0.3.0 のインストールがブロックされ、旧版が端末に残っていることを確認したため、今回の試験版は **別のアプリID** を使用します。

- 旧版（残す）：`jp.taxiapp.gpsprototype` / 画面名「TAXIAPP GPS試験」
- 新版：`jp.taxiapp.gpsprototype.bridge` / 画面名「TAXIAPP GPS連携試験」
- GitHub Release: `gps-distance-bridge-v0.3.1`
- 旧アプリをアンインストールせずに両方インストール可能。ただし **計測データは別々** です。旧版のGPS累計を自動引き継ぎしません。新アプリで新規測定を開始してください。
- 両方で同時にGPSを計測すると電池消費やGPS動作の確認に影響することがあります。テスト時には旧版側を停止してください。
- Google Play プロテクトの「未スキャン」警告はこの対応だけでは消えません。警告の原因・審査状態を確認せずに、Play プロテクトそのものを無効化することは推奨しません。
- GitHub ActionsのDebug APKは実行ごとに署名鍵が変化し得るため、この試験版も今後の同一アプリIDでの上書き更新には適しません。長期更新には固定の安全に管理された署名鍵が必要です。
- 保存済みの旧GPS計測データを消さないために **旧版を削除しない** でください。

## v0.3.2：GPSワンタッチ連携・簡単画面（2026-10-18）
- 画面はGPS累計、測定状態、開始、停止が中心。比較・実車区分・コピー・データ初期化は「詳細」を開いた時のみ表示。
- `taxiappgpsauto://measure` の呼び出しに対して、**アプリ側の二度目の「距離を送る」確認は省略**。ブラウザの押下で送信意図を確認し、固定の試験ページへだけ応答。
- GPS取得時刻の値が古い場合はブラウザが警告する。未測位／GPS停止中は記録を捏造しない。
- 住所取得は最大5秒で打ち切り、取得できなくても距離と押下時刻を返す。
- アプリID `jp.taxiapp.gpsprototype.bridgeauto`、画面名「TAXIAPP GPSかんたん試験」。v0.3.1とは**別アプリ**で共存可能、ただし測定データは引き継がない。旧アプリは削除しない。
- Google Playプロテクトの安全警告は残る可能性がある。未スキャンと明示的な危険検知は区別すること。安全保護の無効化を前提としない。
- 本体の営業日報とは独立。実測はGalaxy Z Fold6で確認する。

## v0.3.3：終了時にGPSを停止、Webテストへのリンクを追加

- アプリ画面から **「GPSテストWebを開く」** を押すと `https://elpapityo.github.io/TAXIAPP/gps-import-test.html` を開きます。
- **「✕ アプリを終了（GPSも停止）」、Androidの戻る操作、履歴からのタスク削除**：GPS測定サービスも停止し、停止状態を保存します。
- **ホーム画面へ戻す、他アプリに切り替える、画面OFF／スリープ**：距離テスト用のGPS測定を継続します。
- WebのGPSボタンで一瞬アプリが起動→自動でブラウザへ戻る `finish()` は明示終了とは区別し、計測を継続します。
- 以前のAPKはデバッグ署名が異なり上書きできないため、アプリIDは `jp.taxiapp.gpsprototype.bridgeexit`、専用起動URIは `taxiappgpsexit://measure` として、旧版と混同しません。計測データは引き継がれません。
- 通常のブラウザ／位置情報利用以外には外部送信しません。GPSの走行精度と端末終了動作は実機で確認する必要があります。
