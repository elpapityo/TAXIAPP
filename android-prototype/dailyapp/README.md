# TAXIAPP 日報 Android 試験版 v0.1.0

## 用途
現行日報の入力・料金計算・履歴画面をそのままAndroidのWebViewAssetLoader(HTTPSローカル資産)上で動作させ、GPS距離だけAndroidのフォアグラウンド位置情報サービスで測定する検証専用APKです。

- パッケージ: jp.taxiapp.dailyapp（GPS距離測定だけのテスト版とは別アプリ）
- 日報本体: ビルド時点の main ブランチをAPKへ同梱。オフラインでも起動します。
- GPS: Android LocationManager、2秒/1m更新要求、画面消灯時も通知を使ったバックグラウンド計測
- 実車・空車: 乗車/降車の操作で切替。降車時は新しい測位を最大8秒待ちます。
- 不確かなGPS・欠測区間を推測加算せず、手入力した距離を尊重します。
- インターネット通信は住所逆変換等の既存機能で使用。営業データをGitHubへ送信しません。

## 検証手順（先に空のテスト乗務で）
1. ダウンロードしたAPKをインストール。既存ブラウザ版とGPS専用試験版はそのまま残す。
2. Androidの「正確な位置情報」と通知を許可。アプリのバッテリー制限を確認する。
3. 停車中に車両トリップを0kmに戻し、アプリで出庫してGPS測定開始。
4. 走行中は操作せず、停車時に乗車・降車を押してGPS実車・空車を確認する。
5. 降車後、最後のGPS確定まで数秒待ってから日報の距離欄と精算保存を確認。
6. アプリを閉じて再起動し、試験乗務の記録とGPSの状態を確認。
7. 車両トリップの実測との誤差、GPS欠測、保存・再起動を記録する。

## 既存データ移行
**テスト中は本番データを移さず、元のブラウザを引き続き正として使ってください。**

将来移す場合はブラウザTAXIAPPの「設定 → データ管理 → 端末一括移行」で暗号化JSONを出力し、別にパスワードを控えます。新しいAndroidアプリの同じ画面でインポートします。インポートは置き換え処理なので、事前に両側のバックアップを取る必要があります。復元後は乗務件数・売上・距離・設定を実際に確認します。Androidのファイル書き出しはDownloads/TAXIAPPに保存します（Android 10以降）。

## 本番移行前に残る課題
- このAPKはDebug署名です。別のビルドを上書きインストールできずアンインストールが必要になる可能性があります。アンインストールすると試験アプリのローカルデータも失われます。
- 正式運用には**固定の署名鍵を安全な場所に保持した署名済みリリース**が必要です。鍵やバックアップを公開GitHubへコミットしないでください。
- バックグラウンドGPS、住所自動入力、実車降車、日報保存とバックアップ/復元は実機で検証が必要です。
- 同じ端末でもChromeとAndroidアプリは別の保存領域で、データは自動共有されません。
- Googleスプレッドシートの本番自動転送は既存の開発状況に依存し、このAPKで新規接続したものではありません。
- 車両トリップと現行日報を正式な記録とし、この試験版を本番日報の代わりには使わないでください。
