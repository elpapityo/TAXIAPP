# TAXIAPP Android 同期試験版 v0.2.0

## 概要
この版は従来のAndroid GPS試験版とは別パッケージです。

- AndroidアプリID：jp.taxiapp.dailyapp.syncpilot
- 日報画面：APKビルド時点のGitHub main（現在 v0.3.37）を組み込み
- GPS：Androidの位置情報フォアグラウンドサービス。実車・空車切替、降車時の追加測位
- 同期：スマホHTML・PC・Android間で同じApps Script受信先の乗務原本を取得／保存
- 競合：Google側の版番号で比較し、同時編集は保留して両版を暗号化してから選択
- 保存：端末内IndexedDBを維持。旧Android v0.1.0のデータは自動移行されません

## 安全な試験方法
1. 現在のHTML版と旧Android試験版のバックアップを保管します。
2. Google Apps Script受信コードを docs/bidirectional-sync.md の手順で更新してから、試験用の乗務で確認します。
3. 新APKをインストール。位置情報・通知を許可します。
4. 新Android版の 設定→Googleスプレッドシート に既存のWebアプリURLと接続キーを設定します。
5. 新Android版の 設定→Googleスプレッドシート→双方向同期 を有効にし、「今すぐ照合」を押します。
6. PC版とAndroid版でそれぞれ別乗務の編集、同じ乗務の編集競合、回線断からの復帰、乗車・降車時距離の記録をテストします。
7. 件数・距離・運賃・送信結果を照合するまで、本番の唯一の保存先にはしないでください。

## 注意点
- このAPKはGitHub Actionsのデバッグ署名で作られます。新規ビルドへの上書きは署名鍵が変わるため失敗する可能性があります。アプリ削除前に必ずバックアップしてください。
- APK内のHTMLとスクリプトは自動更新されません。修正版は新しいAPKの配布が必要です。
- クラウド側の公開Apps ScriptはGitHubを更新しても自動変更されません。
- 端末ごとのGPS値は別の計測器です。スマホとPCから同時GPS計測しないでください。
- Google接続キーはチャット・GitHub・公開スクリーンショットに掲載しないでください。
