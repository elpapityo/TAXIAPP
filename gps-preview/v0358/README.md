# TAXIAPP GPS統合試験版 v0.3.58

試験用URL（GitHub Pages公開処理完了後）：
https://elpapityo.github.io/TAXIAPP/gps-preview/v0358/

このフォルダのファイルは**本番の `/TAXIAPP/` を変更しないための検証専用ページ**です。

## 保存と同期の安全対策
- 本番 IndexedDB `taxiapp-store-v1` は使用しない。専用 `taxiapp-gps-preview-v0358-store` を使う。
- 本番 localStorage `taxiapp-v1`・Android GPS基準・補正キーを使用しない。
- アカウントログイン・操作端末ロックへの接続を起動せず、テスト入力のみローカル保存する。
- Google Apps Script POSTを関数の入口で強制拒否し、自動送信・手動送信・双方向同期も無効にする。
- Android v1.3.0日報検証用APK（別パッケージ、ポート48767）の計測値のみを読取。外部GPSは日報データを書かず、ブラウザから明示操作した欄にだけ反映。
- 模擬GPSは試験ページのチェックが明示的に入った場合だけ利用可能。**試験版に入力したデータは本番に送信しない**。実車の精度試験とは区別する。
- 既存の `index.html` と料金・高速・Google同期の本番スクリプトはそのまま。本番側の `main` に統合ブランチを直接マージしない。

## 端末での操作
1. 旧v1.2.1とは**別アプリ**の[GPS距離ラボv1.3.0 APK](https://github.com/elpapityo/TAXIAPP/releases/tag/gps-diary-v1.3.0)をインストール。
2. APKを開いて実GPSを測定開始（実走行試験）、または模擬0km/hを選んで開始（机上試験）。
3. Android Chromeで上記試験URLを開く。必要ならChromeの「ローカルネットワークへのアクセス」をサイトごとに許可。
4. アプリの「設定」→「GPS距離テスト・位置情報・住所変換」から、GPS距離の取得元を「Android GPS距離ラボ v1.3.0」へ切り替える。
5. 模擬0/40/60km/hを使う場合に限り、同じ設定内の「模擬GPSの距離入力を許可する（この試験版の中だけ）」をONにする。
6. 出庫時の車両トリップ0kmを入力、出庫。その後、待機→迎車/乗車→高速入口→高速出口→降車→入庫の各欄でGPS距離取得を行う。
7. 車両トリップを途中で手入力して補正。走行を続け、次区間のGPS取得がその補正値から増加することを確認する。
8. 再読み込みし、**試験版の**ローカル記録だけ復元されていることを確認する。本番URL `https://elpapityo.github.io/TAXIAPP/` に試験データが混入していないことを確認する。

## 本番反映の判断
Android実機での持続測定、GPS欠測と再測位、手入力との照合、画面消灯時の計測、1乗務を通した日報保存、利用者の実測との突き合わせが終了するまで本番には組み込まない。Cloud/Google同期はこの隔離試験ページで実行できないため、本番同期の検証は安全な別環境とデータ保護設計が必要。
