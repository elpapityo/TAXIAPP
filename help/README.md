# TAXIAPP ユーザー向けWebヘルプ（v0.3.227）

2026年10月29日のクイックマニュアル6ページ・詳しいマニュアル29ページを基準に作成した、静的な操作ヘルプです。一般利用者向けに「まず使う」6ページ・詳しい操作説明26ページ、開発者向け検証記録1ページ、FAQを設けています。

## 構成

- `index.html`: 目次、検索、前後移動、画像の拡大、スマートフォン対応
- `manual-content.js`: 表示する説明と確認状況を含むデータ
- `manual_content.json`: マニュアル引継ぎ用データ
- `manual_text.md`: 文章で閲覧・編集するための原稿
- `images/*.webp`: 添付PDFの実画面の切り出し32枚（クイック6、詳細26）
- `引継ぎ.md`: 出典・確認済み範囲と未検証範囲

## 確認のポイント

ページはアプリ本体とは独立し、保存・決済・GPS・認証・同期・印刷の関数を呼び出しません。アプリ本体への接続は、PCのサイドメニューとスマートフォンの「その他」のヘルプリンクに限定します。

ボタン名・入力項目の説明はv0.3.227の実操作記録を基準にしています。画面写真はPCのテスト画面です。初回登録のGoogle認証・オプチャ名登録、スマートフォンの実機測位、すべての割引・複合決済・高速保存、復元・端末移行・ゴミ箱、通信断・競合解決、管理者のGoogle帳票の実印刷は今回の資料では未検証です。

## 確認方法

ローカルではリポジトリのルートから静的サーバーを起動し `help/index.html` を開いてください。検索、前後移動、画像の拡大・閉じる、スマートフォン幅での目次の展開、画像ファイル32枚の表示を確認します。`index.html` のリンクは `./help/index.html` です。

この作業ブランチは公開・本番反映の承認ではありません。main統合、GitHub Pages正式公開、Firestore設定やGoogle印刷の変更は別途承認が必要です。
