# TAXIAPP（スマートフォン乗務日報）

GitHub Pages 用ブラウザアプリ。GitHub にはアプリのコードのみ配置し、**営業記録・売上・現在地・JSONバックアップ・秘密の認証情報は絶対に登録しません**。

## 起動
GitHub Pages を `main` / `(root)` で有効化すると `https://elpapityo.github.io/TAXIAPP/` から利用できます。

## データ保護
アプリは端末内のIndexedDB（利用できない場合 localStorage）に保存します。**GitHubリポジトリにはデータが送信されません**。旧 `content://` HTML 版から移行する際は、旧版でJSONバックアップを保存し、公開版へ復元後に営業件数・金額を確認してください。古いファイルは確認が終わるまで削除しないでください。

**Googleスプレッドシートへの自動転送は現在未接続です。** 設定項目はまだ自動転送を開始しません。

## 個人情報
GitHub Pages は一般公開です。位置情報のブラウザ権限は端末で許可操作を行い、地図やGPS記録の機能は追加開発・実機確認が必要です。

## 位置情報・住所変換（v0.3.12）
- 位置情報の許可を得た場合のみGPSを取得し、緯度・経度と測位誤差をその乗務記録の内部に保持します。
- 住所変換を有効にした場合、座標を国土地理院の逆ジオコーダーへ送信し、町名・丁目程度の**推定住所**として表示します。番地精度は保証しません。
- 市区町村名は同梱の `municipalities.json`（出典：国土地理院 [gsimaps/muni.js](https://github.com/gsi-cyberjapan/gsimaps/blob/gh-pages/js/muni.js)）から取得します。
- 住所変換が失敗しても座標は保存され、営業入力は継続できます。手動修正した住所は上書きしません。
- **顧客名と位置情報を紐づける機能は未実装**です。将来追加する場合は同意・アクセス制限・削除方法を別途設計します。
- GPSや営業データはGitHubへ公開しません。ただし、住所変換がONの場合、逆ジオコーダーには取得座標が送信されます。
