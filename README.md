# TAXIAPP（スマートフォン乗務日報）

GitHub Pages 用ブラウザアプリ。GitHub にはアプリのコードのみ配置し、**営業記録・売上・現在地・JSONバックアップ・秘密の認証情報は絶対に登録しません**。

## 起動
GitHub Pages を `main` / `(root)` で有効化すると `https://elpapityo.github.io/TAXIAPP/` から利用できます。

## データ保護
アプリは端末内のIndexedDB（利用できない場合 localStorage）に保存します。**GitHubリポジトリにはデータが送信されません**。旧 `content://` HTML 版から移行する際は、旧版でJSONバックアップを保存し、公開版へ復元後に営業件数・金額を確認してください。古いファイルは確認が終わるまで削除しないでください。

**Googleスプレッドシートへの自動転送は現在未接続です。** 設定項目はまだ自動転送を開始しません。

## 個人情報
GitHub Pages は一般公開です。位置情報のブラウザ権限は端末で許可操作を行い、地図やGPS記録の機能は追加開発・実機確認が必要です。
