# Googleシートで「Firestoreから取得」を使うための本番導入手順

**状況：GitHub上のGASコードとテストは完成。接続済みGoogle Drive/SheetsツールにはApps Scriptのコード更新・実行機能がないため、既存GoogleシートのB20はまだリンクのまま。本番での取込実績は未確認。**

## 完成後の画面

既存 `TAXIAPP_印刷操作` シートを保護し、次の項目だけ新設する。

| セル | 表示・操作 |
| --- | --- |
| A20 / B20 | `Firestore取得 ▶` / チェックボックス |
| A30 / B30 | 取得する乗務日 / `YYYY-MM-DD` |
| A31 / B31 | 同日に複数あるときだけ指定する乗務ID |
| A32 / B32 | 取込結果（更新番号、成功または保留理由） |

`B15`・`B17`・`C17`、印刷用2ページ、旧Google原本、現行計算式・マクロは変更しない。

## 本番適用

1. 既存シート「TAXIAPP_日報・補助簿印刷」の **拡張機能 → Apps Script** から紐付く実GASプロジェクトを開く。**現在のスクリプトファイルとappsscript.jsonを丸ごと退避**。利用中の既存Webアプリの版番号・設定も記録する。
2. 本番GAS側で現在の `Code.gs`、`FirestorePrintPullDraft.gs`、`FirestorePrintSourcesDraft.gs` の存在と実装一致を照合。未導入分を追加する場合は、現行 `doPost`・`onOpen`・印刷関数を消したり置換したりしない。
3. 本プロジェクトの `FirestoreSheetDirectImport.gs` を**追加ファイルとして**導入。他のGASファイルと関数名衝突がないことを確認する。
4. **スクリプトプロパティ**に `TAXIAPP_FIRESTORE_PROJECT_ID`、`TAXIAPP_FIRESTORE_OWNER_UID`、`TAXIAPP_FIREBASE_WEB_API_KEY`、`TAXIAPP_PRINT_OWNER_EMAIL` が本人環境の値で設定されていることを確認。追加情報・IDトークン・秘密鍵はGitHubに公開しない。
5. Apps Script OAuthの必要なスコープは、既存シート操作、`script.external_request`、`script.scriptapp`、本人メール照合、Google OAuth。既存のOAuthスコープやトリガーを削除しない。初回実行時の権限承認は本人アカウントが行う。
6. GASエディタから **`setupFirestoreSheetImportButton_` を一度実行**。シート上の B20 をチェックボックスに変更し、A30〜B32を設定、必要な設置型`onEdit`・`onOpen`トリガーを追加する。既存値があると停止し上書きしない。同じ設定済み欄での再実行は入力済みの日付と結果を維持する。
7. 既存のWebアプリ`/exec`は**シート内チェック操作だけなら再デプロイ不要**。設置型トリガーはスクリプトの現行HEADコードを実行する。PC TAXIAPPから`/exec`へ新しい`firestorePrintProbe`処理を送るなら別途新しいWebアプリ版の公開が必要。

## 初回取込の安全な確認

1. **実営業データのバックアップを確認**し、PCの本人Googleアカウントで操作。シートにログインしたアカウントと固定本人メール、Firebase UIDが一致しなければ取込停止。
2. B30 に本人Firestoreの入庫済み日報の日付を入力。同日に複数乗務があるならB31に正確な乗務IDを入力。B20をチェック。
3. 実行はユーザー確認のある1乗務のみ。サーバーID・更新番号・本文一致・旧Google原本とのID重複、既存4印刷元の更新可能性を照合。金額・距離の独自再計算はしない。
4. B32に転送結果が表示され、4印刷元の対象乗務ID・件数・明細・金額と原本が一致することを実Googleで読戻し確認。その後、従来どおり B15/B17 で印刷対象を選び、**既存補助簿2ページを確認**する。
5. 複数乗務、通信失敗、本人不一致、金額相違、更新中の競合、同一IDの旧Google原本があるときは停止し、無断で再送・上書き・削除しない。B32が「取込未確認」の場合は4印刷元を先に照合する。

## 負担と復旧

- 別の新シートを作ったり、本番の旧Google原本を消したりしない。
- 失敗時は新設トリガーだけを無効化し、B20を元のリンクへ戻せる。既存GASソースと印刷操作シートは事前バックアップから復旧する。
- この手順で初めて本番からの取得・既存補助簿の反映が確認できた場合のみ「完成」と報告する。GitHubでの合成テスト成功だけで本番完了としない。
