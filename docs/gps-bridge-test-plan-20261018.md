# GPSアプリ→ブラウザ 距離・住所・時刻の簡易テスト

## 目的
Android試験版GPSアプリに蓄積された「GPS累計距離」を、ブラウザ試験画面の **GPS** ボタンを押した時点で取り込む。車両の日報データを変更しない。住所と時刻も各行の横に表示する。

- URL：`https://elpapityo.github.io/TAXIAPP/gps-import-test.html`
- GPS APK：Android試験ブランチ `prototype/android-background-gps-20261016` の **v0.3.0**（距離＋住所＋時刻連携）
- 現行本体 `index.html` のデータ保存、Google送受信、GPSブラウザ計測と独立した画面。
- 従来GPS APK v0.2.0はディープリンクに未対応。`計測結果をコピー` を貼り付けるテストのみ可。旧形式には住所がないため「住所は取得できない」と表示し、時刻は取り込み操作時刻になる。
- スマホChromeがアプリから戻る際に別タブを開く可能性がある。**同じタブへの復帰はGalaxy Z Fold6実機で確認が必要。** 失敗時はコピー方式を使い、データ保存はしない。

## 距離の計算
1. スタート距離＝車両の計測開始値。初期値は0.000km。
2. スタート行のGPSボタンでGPSアプリの累計値を記録（例：GPS累計4.200km）。
3. 1行目のGPSボタンを押す（例：GPS累計5.200km）。結果＝スタート0＋(5.200−4.200)＝1.000km。
4. 1行目に**20**を手入力して補正。結果20.000km。
5. 2行目のGPSボタンを押す（例：GPS累計5.950km）。結果＝**20.000＋(5.950−5.200)＝20.750km**。
6. 以後の行でも繰り返す。前の行の手入力値が変わったら、続く結果を再計算する。
7. 増分を正しく求めるには、**必ずスタート→1→2の順にGPSボタンを押す**。手入力値のみでGPS基準が不明なら、自動計算しない。
8. GPS測定が停止・欠測・古い状態なら警告を出す。GPSがリセットされた場合や古い応答を受けた場合は転記しない。

## 各行の表示
| 左：入力・補正 | 中：取得操作 | 右：結果 |
|---|---|---|
| 0.000 ／ 20.000 等 | GPS | 1.000 ／ 20.000 ／ 20.750 等 |

下段で **住所（アプリのAndroid Geocoderによる逆ジオコーディング）** と **取得時刻（日本時間）** を表示。住所変換できなければ「住所未取得」と明示。住所は位置の精度・通信状態・端末のサービスに依存する。

## 安全・個人情報
- GPS位置座標をブラウザに転送しない（Android側は現在地を住所へ変換し、住所文字列だけ返す）。Androidの逆ジオコーディングは端末提供サービスで処理され、通信を伴う場合がある。
- ブラウザ側は位置座標を取得せず、日報・Firebase・Apps Scriptへデータ送信しない。
- GPSアプリ側には住所を永続保存しない。ブラウザ画面は一時的なテスト値のみ利用。旧画面を閉じるまではセッション上に値を保持する。
- GPS連携リクエストは32桁ランダムnonce、120秒有効期限、対応距離キー、時刻を照合。許可された固定のテストページにだけ戻す。
- 車両トリップとの計測誤差を事後比較し、GPS距離を無条件に正式な営業距離として採用しない。
- **運転中にボタン操作しない。** 乗降時・停車時のみ操作。
