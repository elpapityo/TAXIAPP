# IC位置データのテスト投入仕様

## 現在の状態
IC名取得テストページは外部API検索を廃止し、利用者が選択したJSONファイルの座標とGPSを照合します。公式の全国データZIPは取得環境のDNS障害により未取得であり、**本物のIC位置データは未投入**です。架空座標は登録していません。

## JSON形式
UTF-8 JSON。配列または {"items":[...]} を受け付けます。

```json
{"items":[]}
```

各要素の必須項目: `name`（文字列）, `latitude`（数値）, `longitude`（数値）。任意: `road`, `type`, `direction`, `id`, `source`, `verified_at`。

公式データを変換するときはIC・JCTの代表点と入口／出口のランプ位置を区別し、位置の根拠を記録してください。高速料金・方向別通行可否はこのテストでは判定しません。
