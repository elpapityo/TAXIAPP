# TAXIAPP 印刷V2：実機テスト直前の準備と操作手順

**2026年10月21日／開発PR #115用。運用中のTAXIAPPとは完全に別の合成データ試験。**

## 実装した確認用画面

- `labs/print-v2-device-preview.html`：単体のHTML。外部JavaScript・外部通信・ログイン・GPS・Google接続・Firebase接続・IndexedDB/localStorage・実データ操作は持たない。認証を模擬できるだけで実際の利用者アカウント情報は使用しない。
- 1、36、37、60件の合成営業データで補助簿1ページ目・2ページ目の振り分けを確認。GO受取手数料は会社納金へ含め、Uber配車手数料は納金から差し引く。現金＋QRの複合決済とキャンセル金額0円を表示。
- B15=最新乗務/B17=手動選択/C17=選択IDを、既存シートとは**つながない**独立したUIで再現。合成データのみの印刷プレビュー（`window.print()`）を明示操作した場合だけ開く。
- 14項目の自動模擬確認結果と画面サイズを表示。操作結果をコピーできないモバイル環境ではスクリーンショットで共有できる。
- GitHub Pagesの`main`配信先は変更していない。開発PRのファイルをそのまま公開URLと勘違いしないこと。配布するHTMLファイルを端末で開く方法のみ。

- `tests/print-v2-device-preview.test.js`：ネットワーク、外部スクリプト、認証情報、端末データ保存APIを含まないこと／開発本体と未接続であること。
- `tests/print_v2_device_browser_e2e.py`：Chromeのスマホ縦390x844、横844x390、タブレット768x1024、PC1280x850相当で1/36/37/60件（1ページ目・2ページ目 1+0、36+0、36+1、36+24）と、B15/B17/C17、合成データ印刷操作、オフラインでも画面機能が動くこと。 ChromeのPDF出力でもA4横向き2ページに収まることを各ケースで確認（実際のプリンターの余白・給紙・印字については未確認）。
- `server-drafts/print-stage-v2-firebase-admin-adapter.js`：実運用向け接続先の**未公開サーバー用部品**。将来のFirebase Admin SDKに`verifyIdToken(token,true)`を要求、Firestore `admins/{uid}` 管理者権限・本人 `privateDuties/{uid}/shifts/{id}`・`tombstones/{id}` の確認を設計。原本と削除履歴は同一トランザクションで読込み、マーカーが未存在・削除中・版違いなら拒否する。**本物のSDK初期化・サービス実行環境・本番読込はしていない**。テストは模擬SDKによる。
- `tests/print-stage-v2-firebase-admin-adapter.test.js`：本人UID、管理者権限なし、認証失効、原本なし、マーカーなし、削除、更新番号不一致を検出する合成データ回帰。
- GitHub Actionsの4系統（Node/GPS/Chrome/Firestore Emulator）は、承認された開発ブランチで確認する。実際のAndroid・iPhone・プリンターは**まだ未検証**。

## 実機で行っていただきたいテスト（次の段階）

1. チャットで渡した`TAXIAPP_印刷V2_実機テスト_合成データ.html`を、スマホまたはPCのブラウザで開く。**普段のTAXIAPPは開いたままでも問題ない**（通信・端末データ保存なし）。
2. 最初の「模擬テスト成功 14/14」を確認。スマホで画面を縦→横にして、文字やボタンの重なり、不要な横スクロールがないか確認。 iPhoneでダウンロードファイルのプレビューだけが開かれてボタンを操作できない場合は、OS側の制約の可能性があるので、セキュリティ設定を変更せず画面を共有してください。
3. 営業件数を「1件」「36件」「37件」「60件」と変更し、1・2ページ目の件数が順に「1+0」「36+0」「36+1」「36+24」になることを確認。
4. 「B15：最新の乗務を自動選択」のチェックを外し、B17で別の合成乗務を選択。C17の長い乗務IDが切り替わることを確認。B15をONにすると最新の合成乗務に戻る。
5. 「合成データを印刷プレビュー」を押し、印刷プレビュー上で2ページへの分割・文字サイズ・用紙の見やすさを確認。実印刷せずプレビューだけでもよい。**紙に出す場合も合成データのみ**。
6. 問題があればスクリーンショットと操作（画面の縦/横、営業件数）をこのチャットへ送る。問題なければ「実機テスト問題なし」でよい。

### 作業を止めている本番接続

- **このHTMLは実際の既存補助簿シートや本番日報を表示できない。** 本番Firestoreのデータを端末へ戻す機能ではない。
- 本番の管理者Firestore原本化・旧Google同期原本からの移行・既存印刷シートの選択式切替・GAS再デプロイはまだ行っていない。
- 本物のFirebase Admin署名・失効検証と管理者権限・サーバー接続には、本人が承認した安全な稼働環境と認証・Googleへのデータ転送が必要。いまの署名検証はモックであり**本番動作済みとは言わない**。
- 現在の本番旧Google同期原本は変更・削除しない。全件一致・紙補助簿・実端末の相互同期は別工程で検証し、操作の影響・バックアップと戻し方を示した上で明示承認を取る。
