# GPS距離ラボ v0.6.0 — 0km基準不具合・重複UI修正

このAPKは既存の日報、売上、同期データを操作しない独立した距離検証用アプリです。

## 画面の整理
- **GPS計測画面（ネイティブ）**：GPS開始・停止・内部累計・受信状態を表示。Webと重複する0km基準、区間比較、補正入力は配置しません。
- **距離テストWeb画面（APK内蔵）**：0km基準、GPS累計とボタン間距離、車両トリップ手入力、補正後距離だけを操作。アプリ内のボタンから表示。Chromeは開きません。
- 公開 `distance-console.html` はWebのUIプレビューです。Chrome単独でAndroid GPSに接続する機能は未実装です。

## 0km不具合への対応
- GPSが起動していても測位直後などは値が未準備で、従来は即座に拒否され、エラーが画面最下部だけに出ていました。
- 今回は0km基準ボタンを押すと、最後の有効GPS測位を確認するまで **最大30秒待機** し、受信したら自動で記録します。
- 30秒経っても有効GPSがない場合は0kmを記録したふりをせず、ボタン直下に理由を表示。再度押せます。
- 有効GPSの時刻を無効位置ジャンプから分離して管理。GPS開始時には過去の有効GPS時刻をクリアします。
- 欠測の履歴だけを理由にその後の全測定を永久に拒否せず、記録時に補正を推奨します。未計測の距離を勝手に追加しません。
- GPS計算式・日報・Google同期は変更なし。

## インストール
- パッケージ `jp.taxiapp.gpsprototype.distancelabv060`、表示名「GPS距離ラボ 計測」。
- GitHub ActionsのDebug署名は固定されないため、旧v0.5上書きではなく別のアプリとしてインストールします。データは移行しません。
- Androidの正確な位置情報の許可が必要です。キー、Google Maps有料API、インターネット通信は不要。
