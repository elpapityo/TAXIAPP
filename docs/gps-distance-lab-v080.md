# GPS距離ラボ v0.8.0 — 外部ブラウザからのGPS取得修正

## 現象（実機スクリーンショット）
- GPS計測側では内部累計 **1.372km**、有効GPS受信 **26秒前**、GPS欠測0回。
- Chromeの外部Web画面では **0km基準点は正常に記録済み**（ZERO SET）だが、その後の「GPS取得」を押しても距離が受け取れない。
- v0.7.0は有効GPS 15秒以内しか返さない仕様。車両停車中のminDistance=1mや端末GPS更新停止で受信時刻が26秒以上になった場合、残存GPS距離があっても30秒待機して失敗する。

## 対応
- Android GPSの連続取得を距離間隔1m→0mに設定し、停車中も有効測位が届きやすくする（2秒間隔の要求は維持）。
- ブラウザのGPS取得要求時、最後の有効GPSが15秒より古い場合はAndroid前景GPSサービスに **ACTION_REFRESH** を送る。Android `LocationManager.getCurrentLocation` でGPS_PROVIDERの有効な現在位置の再取得を要求。重複リクエストは6秒間隔で抑制し、18秒でキャンセルする。
- 15秒より古いキャッシュ座標は新しいGPS扱いにしない。OSがGPSを返さない場合も距離を捏造せず、30秒後に取得失敗を理由付きで表示する。
- Webの取得ボタン近くに「GPS再測位中（有効GPS 26秒前）」等の状態をリアルタイム表示する。0km基準は従来どおり記録維持。
- GPS累計・車両トリップ手入力補正の既存計算は変更しない。GPS位置の精度45m上限、移動速度外れ値検出は維持。
- Chrome等の**外部ブラウザ**のみ使用し、組込WebViewなし。GPSデータは `127.0.0.1:48764` に限定したスマホ内部のローカルHTTP（通信キー・Google有料API・外部ネット不要）。v0.7のポート48763と衝突しない。
- この試験版はDebug署名が固定されていないためパッケージ `jp.taxiapp.gpsprototype.distancelabv080`、アプリ表示名「GPS距離ラボ v0.8」。旧v0.7のGPS測定は停止してから使用してください。

## 操作
1. v0.8アプリを開きGPSを開始。
2. 有効GPSの受信を確認したら「外部ブラウザで距離テストを開く」を押す。
3. Chromeで`http://127.0.0.1:48764/`が開く。同じタブの「GPS取得」で再測位待ちから自動取得する。
4. Chromeの0km基準および手入力距離は、アプリ v0.7とは別のブラウザストレージキーに保存される。旧ブラウザのデータは変更しない。
5. 正確な位置情報の許可とGPSの屋外受信が必要。再測位が失敗した場合、画面に理由が表示される。

既存のTAXIAPP本番日報、顧客データ、Google同期は変更しません。自動検査が通ってもAndroidの実際の走行精度は未検証です。
