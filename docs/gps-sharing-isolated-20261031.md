# TAXIAPP｜位置共有 独立試験版（第1段階）

## 先行実装
- 既存Googleログインを使う独立画面。別アカウント不要。
- 既存の出庫・入庫データを読取専用で確認し、営業中だけ現在位置を共有する。
- 公開初期値ON。非公開時は管理者を含め他者から不可視。
- 登録利用者の地図、5つの営業状態、一覧、現在地ボタン、5分更新切れ非表示。
- 走行時15秒、停止時90秒を送信目標とする。ブラウザ表示中のみGPS取得。
- GPS位置飛び検出の75m/sは仮の閾値。実機データで検証が必要。

## まだ実装していない範囲
- GPS履歴の30秒ごとの端末保存・乗務別静止地図・UTF-8 BOM付きCSVの書き出しはブランチへコード追加済み。実機では未検証。入庫時のクラウド同期は未実装。
- 管理者のGPS履歴閲覧・監査ログ、クラウド保存と期限切れ自動削除。
- iPhone/Androidの実機GPS、通信断、2名間の実際の位置共有。
- 本体TAXIAPPへの正式統合・本番公開。

## 必ず区別する点
- コードは作業ブランチ上。現行mainと公開版は変更しない。
- 現行firestore.rulesはgpsPresenceとgpsSharePrefsを許可していない。
- docs/gps-sharing-firestore.rules.fragmentは未適用の提案である。
- Firestore本番ルール・認証権限の変更には別途事前承認が必要。
- 現時点でクラウド位置送信・他者閲覧は実機動作確認できていない。端末保存履歴もブラウザ・実機未検証。
- 既存日報原本、売上、料金、高速、GPSトリップ、印刷は変更しない。
