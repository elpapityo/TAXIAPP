# GPS距離ラボ v1.0 — 外部ブラウザ接続元の照合

## 2026年10月19日 12:55 の実機画像から
Chromeは`127.0.0.1:48764`を表示しているが、v0.9に追加した「再取得」「200mなら0.200と入力」が表示されず、旧版の「取得済み」が残る。GPS有効受信は0秒前・精度±4mで、GPS受信そのものとは別の問題。

## 原因・対策
- v0.8とv0.9の別アプリが同じローカルポート48764を利用。旧GPSサービスがポートを利用中に新アプリを起動すると、新アプリのローカルサーバーが起動できず、Chromeには旧アプリのHTMLが表示されてしまう。
- v1.0アプリはブラウザを開く前に`GET http://127.0.0.1:48764/api/identity`でサーバーのmarker・Android package ID・Web versionを検証。一致しなければ旧アプリ停止の案内を表示し、間違ったブラウザ画面を開かない。
- Android GPS計測画面にWeb接続エラーを表示。ポート競合をGPS欠測と混同しない。
- Webの目立つ場所に`Web v1.0`と表記し、画面の新旧を確認可能にする。
- Chromeの`127.0.0.1:48764`と`localStorage`キー`gps-distance-lab-browser-v080`を保持。0km基準・GPS累計・補正の保存値は**消さない**。
- アプリpackage IDは`jp.taxiapp.gpsprototype.distancelabv100`、表示名「GPS距離ラボ v1.0」。Debug署名上書き衝突を避けるため別アプリ。
- 外部Chrome、タブ増加なし、端末内部のみ通信、APIキー不要。業務日報は未変更。

## 正しい操作
1. 旧v0.8・v0.9のGPS測定を停止（Chromeの保存データ削除不要）。
2. 新v1.0のアプリでGPS測定開始。
3. 「外部ブラウザで距離テストを開く」を押す。v1.0のサーバーが動いていればChromeが開き、**Web v1.0**が表示される。
4. 接続先を使う別アプリが動いている場合は、警告ダイアログで旧アプリ停止を促す。

現段階で自動ビルド・計算テストは可能だが、実機での再確認は必要。
