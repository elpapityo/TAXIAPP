# GPS距離ラボ v0.7.0 — 外部ブラウザ版

## 利用者からの要求
「アプリ内ブラウザは不要。外部ブラウザを利用する」ことを最優先に、v0.6の組み込みWebViewを廃止。

## 操作と役割
1. APK「GPS距離ラボ 計測」を起動し、GPS測定を開始。
2. 位置情報「正確な位置情報」を許可し、GPSの有効受信を確認。
3. 「↗ 外部ブラウザで距離テストを開く」を1回押す。Chromeなどデフォルトの外部ブラウザで `http://127.0.0.1:48763/` が開きます。
4. **同じブラウザタブ**で「ここを0kmとして記録」、走行後の「GPS取得」、車両トリップ距離の補正を行います。GPS取得ごとにタブやアプリを切り替えません。
5. GPSを停止するとローカルサーバーも停止し、ブラウザのデータ取得は停止します。GPSを再開したら同じタブを再読込します。

## 技術仕様
- GPS計測はAndroid Location foreground service。通知と画面OFF中の計測は従来のGPS計測ロジックを保持します。
- 同じGPSサービスが端末内ループバック `127.0.0.1:48763` でHTTPサーバーを提供。API: `GET /api/status`、`GET /api/capture?nonce=...&target=...`。ブラウザは通常の同一オリジン`fetch`で取得。
- 0km基準ボタンは最大30秒の有効GPS受信待ち、未取得ならボタン直下にエラー。ブラウザの`localStorage`にだけ基準点・補正値を保存。
- Web UIはAndroid APKに同梱され、外部ブラウザへ端末内HTTPで提供されます（WebViewは使用しません）。
- HTTPは127.0.0.1のみにbindしHostヘッダーを厳密に検証、読み取り専用GETのみ、CORSは公開しません。機密の位置座標、住所、認証キーは返しません。
- 端末内ループバックのためGoogle Maps APIは不要、課金なし、外部ネット接続なし。
- **注意**：Chromeなどのブラウザ自体は外部アプリです。AndroidのローカルHTTP通信に`INTERNET`権限が必要ですが、インターネット回線へのアクセスは行いません。
- v0.6とは別パッケージ `jp.taxiapp.gpsprototype.distancelabv070`（Debug署名がビルドごとに変わる可能性があるため）。旧バージョンは保持できますがGPSとWeb記録は移行しません。
- `https://elpapityo.github.io/TAXIAPP/distance-console.html` は見た目の公開プレビューのみ。GPS連携はアプリが起動する `http://127.0.0.1:48763/` の外部ブラウザから行ってください。
- 日報`index.html`、既存の日報データ・同期・顧客情報の変更なし。実機での実走行検証は未完了です。
