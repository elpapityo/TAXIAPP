# GPS距離ラボ v1.2 模擬走行テスト

目的：スマートフォンを移動させずに、Androidアプリが生成・積算した模擬距離を、外部ChromeがHTTPで読み取り、0km基準、地点登録、車両トリップ補正、次の登録を試せるようにする。

操作：アプリで「模擬走行テスト開始（0km/h）」→ 外部ブラウザで127.0.0.1:48765を開く→ 0km基準を登録 → アプリに戻り「模擬40km/h」→ 30秒待つ → Chromeの同じタブでGPS取得 → 0.5kmなどへ補正 → さらに模擬移動して次のGPS取得。0km/hに戻せば位置は動かない。

- 模擬座標はAndroidアプリ内部だけで生成。OSのGPS座標や他アプリの位置を変更しない。
- 模擬モードではAndroid GPS LocationManagerは使用せず、同じTripAccumulator計算エンジンへ模擬Fixを送り、現行のアプリ内ループバックHTTP・ブラウザJSを通過する。
- 初期速度0。選択可能速度0/20/40/60km/h。アプリの画面を切り替えてもGPS foreground serviceが生きている間は継続。
- アプリのIDはdistancelabv120、ポート48765、Chromeの記録キーはgps-distance-lab-browser-simulator-v120。実GPS版v1.1のデータと混同しない。
- アプリとWebに「模擬走行」「架空データ」と表示。模擬結果は営業日報や実走行の証明に使わない。
- Androidの位置情報権限は位置情報前景サービスを起動するために必要だが、模擬モードでは実GPS測定を購読しない。
- 本番TAXIAPP、顧客データ、日報は変更しない。

重要：人工データでの通信試験であり、Galaxyの実GPS精度や長時間バックグラウンド動作までは検証しない。
