# TAXIAPP：PCからスマートフォンへの一括引き継ぎ／テスト乗務削除

## パソコンの設定をスマホへ一括引き継ぐ

1. **移行元のPC**で [TAXIAPP](https://elpapityo.github.io/TAXIAPP/) を開き、設定 → バックアップ → 「PC → スマホ　一括移行」を開く。
2. PCでGoogleスプレッドシートの **WebアプリURLと接続キーが実際に保存されていること**を確認する。入力だけでなく、保存された接続設定と必要な営業記録が揃っているPCを移行元に選ぶ。
3. 12文字以上の移行パスワードを2回入力して「暗号化して一括書き出し」を押す。
4. 作成された `TAXIAPP_端末一括移行_日付.json` を、USB接続など安全な方法でスマホに転送する。ファイルとパスワードは別経路で扱い、GitHub・チャット・公開共有フォルダーに載せない。
5. **移行先スマホ**のTAXIAPPを開き、設定 → バックアップの「② スマホ」欄でファイルを選び、パスワードを入力して一括上書きを開始する。
6. PCとスマホの件数を確認し、スマホの旧データの**暗号化バックアップが確実に保存されたことを確認**してから最終確定する。
7. 復元後は「設定 → Googleスプレッドシート」で接続先・接続キーの有無を確認し、**手動送信で1乗務の受信確認**を行う。成功後、必要に応じて自動送信に切り替える。

## 上書きの対象

- 乗務・営業・待機・GPS履歴など、端末保存されている `model` 一式
- 登録した乗務員・車両、待機場所、料金、表示、入力、送信などの `prefs`
- Apps Script WebアプリURLと送信先GoogleスプレッドシートURL
- 別保存されている送信用接続キー

移行元と同じGoogleアカウントへのログイン状態、Chromeの位置情報許可、Google Apps Scriptのデプロイそのもの、クラウドの印刷帳票は移行対象外です。移行中にGPSが観測できない時間は補完しません。

**上書きは自動的なPC・スマホ双方向同期ではありません。** 上書き後も各端末の保存領域は別々です。同時に2台で営業記録を編集しないでください。

## 出庫〜入庫単位でテスト記録を削除する

- 設定 → バックアップ → 「テストデータを削除」を開く。
- 1行が「出庫時刻 → 営業複数件 → 入庫時刻」の1乗務を表す。
- 対象の日付・時刻・営業件数・メーター売上を確認して「この乗務を削除」を押す。
- 乗務中や未入庫のレコードは削除不可。
- 対象乗務の全営業・待機・GPSは端末内から消えるが、別の乗務・設定は残る。

**重要**：この削除は端末内データのみです。既にGoogleシートへ送信した乗務は自動的には削除されません。クラウド側の不要なテストデータを取り除く場合は、受信元・関連集計・印刷シートの整合性を検証した別の削除手順が必要です。

## 安全性

移行用ファイルはブラウザの Web Crypto API（PBKDF2-SHA256、310,000回＋AES-256-GCM）で暗号化します。暗号化・復号は端末内のみで行い、ファイルの生成・読込に外部の暗号化サーバーを使いません。パスワードが不明なときは復元できません。

通常の旧形式JSONバックアップ（追加インポート方式）と、新しい暗号化一括移行ファイルは別形式です。取り違えた場合はエラーとなります。
