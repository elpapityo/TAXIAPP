# GPS距離ラボ v1.1 — 旧0km基準を履歴保存し新規測定

## 実機で報告された問題
- GPS計測アプリと外部Chromeとの接続先は一致したが、以前の0km基準（12:54:42）がChromeに残り、「ここを0kmとして記録」が無効になった。
- Androidは新アプリのためGPS距離累計が0kmへ戻り、以前のChrome基準点と一致しない。既存地点に「取得済み」が残り、新しい走行のGPS取得ができない。

## 修正
1. Webに**「＋ 新しい計測を開始（旧記録は保存）」**を追加。以前の0km基準が登録済みでも押せる。
2. 確認後、旧基準点・GPS値・日時・補正値をChromeの`gps-distance-lab-history-v110`へ保存してから、新しい入力用状態を作る。保存できなければ旧状態を残す。
3. 「過去の計測履歴を確認」で履歴を閲覧できる。
4. Android計測開始ごとに`runId`（UUID）を新しく発行。ブラウザは0km基準をrunIdと紐づけ、別GPS測定の距離が混在したら新規開始を促す。
5. 同じ外部ChromeのURL`http://127.0.0.1:48764/`と、既存Web保存キー`gps-distance-lab-browser-v080`を維持して旧データを保護する。外部ブラウザ・タブ増加なし。
6. 新APKは`jp.taxiapp.gpsprototype.distancelabv110`（GPS距離ラボ v1.1）。旧v1.0等のGPS測定を停止した後に使用する。
7. 本番日報・顧客・Google同期には変更なし。実機でのGPS距離計測精度は未検証。

## 検証
旧0km基準4.750km、保存GPS5.000/5.300km、車両手入力0.250/0.550kmを履歴へ保存。新GPS開始0kmから0km基準を新規登録して0.375km取得した際に、GPS区間0.375kmが表示されることを自動テストで検証。
